# 开篇：为什么用 GitHub 记笔记

## 背景

从今天开始系统学习 AI，需要一个地方把学到的东西沉淀下来。试过本地文档，问题是：

- 版本混乱——"笔记_最终版_再改.docx"越攒越多
- 换设备就断了
- 想回头找某个结论，只能翻文件夹

用 GitHub 记录，这几个问题都能解决。

## 这个仓库打算怎么用

1. **一篇笔记一个文件**，放在 `notes/` 下，文件名带日期，方便按时间排序
2. **代码实验放 `scripts/`**，笔记里引用对应脚本
3. **每篇笔记写清三件事**：概念是什么、我理解到什么程度、能用在什么场景
4. **做一些和学习配套的小游戏**，把抽象概念做成能跑起来、能上手玩的东西

## 内容边界

这个仓库是公开的，所以只放：

- 公开资料的整理与个人理解
- 自己写的练手代码和小游戏
- 对工具用法、学习方法的观察

**不放**：工作相关的项目数据、内部参数、客户信息、任何涉及保密的内容。这类东西即使放私有仓库也不合适，留在本地就行。
